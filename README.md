# Ритм (Ritm)

Приложение для трекинга привычек и задач.

- Веб: https://web-ritm.vercel.app/
- Версия: **Ritm v2** (`versionCode: 2`)

## Структура

- `index.html` — веб-приложение
- `vendor/` — React, ReactDOM, Supabase
- `version.json` — актуальная версия для автообновления APK
- `ritm.apk` — (опционально) положите APK сюда или в GitHub Releases

## Обновления APK

Приложение раз в сутки (и по кнопке в настройках) запрашивает `version.json`.
Если `versionCode` больше локального — уведомление и кнопка скачивания.
